# Team Impact Manifesto

- `index.html` is the full manifesto, for sharing as a link.
- `short.html` is the one-pager. Open it in a browser at 1080px wide and screenshot it for WhatsApp.

## Publish on GitHub Pages
1. Push this folder to a GitHub repo.
2. In Settings → Pages, choose the `main` branch, root folder.
3. Share `https://<your-username>.github.io/<repo>/`. The short version is at `/short.html`.
